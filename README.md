# Get Started with C#

## My C# learning progress

I'm a third-year software engineering student learning C# through Microsoft Learn. This fork records my exercise implementations and learning progress. The original exercises and starter code are provided by [Microsoft Learning](https://github.com/MicrosoftLearning/mslearn-csharp-programming).

### Completed: Guess the Number

- Generate a random number between 1 and 20.
- Read guesses from the console, with a maximum of five attempts.
- Use a `while` loop, `if` / `else` conditions, and `break` to control the game.
- Display hints and the final result.

This exercise targets .NET 10. With the .NET 10 SDK installed, run it from the repository root:

```bash
dotnet run --project Labfiles/06-create-guess-the-number-game
```

The exercise currently expects integer input; handling invalid input is a next step.
